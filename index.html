Tres tests antes de dinero real

El P&L de la ventana de papel no es criterio de ningún test — se reporta con su banda ±2σ y no decide nada.

T1 · VALIDACIÓN (backtest OOS)
  • T1.1 Sharpe OOS > 0 en ≥60 % folds anuales y agregado > 0
  • T1.2 Sharpe OOS ≥ equal-weight del universo + 0,15
  • T1.3 maxDD OOS ≤ 1,25 × maxDD del equal-weight
  • T1.4 Robustez ±50 % parámetros — ≥2/3 variantes dentro del 30 % del base
  • T1.5 Turnover y exposición media documentados (contrato para T3)
T2 · OPERACIÓN (60 días papel, ~20 oct)
  • T2.1 ≥58/60 runs diarios limpios por CI · 0 intervenciones manuales
  • T2.2 0 discrepancias en replay audit semanal
  • T2.3 Guardarrailes: 0 falsos positivos/negativos auditados
  • T2.4 Datos verificados · rechazos resueltos en ≤72 h
T3 · FIDELIDAD (papel vs contrato T1)
  • T3.1 Turnover papel dentro de ±50 % del esperado (T1.5)
  • T3.2 Exposición media dentro de ±15 pp de la esperada
  • T3.3 Tamaños de operación consistentes con el backtest
  • T3.4 Divergencia papel-vs-simulación diaria = 0 (mismo código y datos)
Los tres PASAN → Gate B (Kraken micro) → Gate C (€500 con breakers). Cualquier FAIL → diagnóstico; arreglo de estrategia reinicia T2/T3.
